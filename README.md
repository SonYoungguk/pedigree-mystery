# 🖼️ 가문의 초상 — 유전 가계도 미스터리

중학교 3학년 과학(유전) 수업을 위한, 러스티레이크풍 포인트 앤 클릭 방탈출 미스터리 게임입니다. 빌드 도구 없이 브라우저에서 열기만 하면 동작합니다.

**바로 플레이:** https://sonyoungguk.github.io/pedigree-mystery/

## 소개

할머니가 돌아가셨지만 엄마는 장례식에 오지 않았다. 할머니가 남긴 언덕 위의 집에는 평생 생물 선생님이었던 할머니가 기록해 둔 가족의 보조개, 혈액형, 적록색맹이 곳곳에 남아 있다. 다섯 개의 방에서 그 기록을 읽어 나가며, 엄마와 할머니 사이에 무슨 일이 있었는지 알아낸다.

보조개(우열 · 유전자형) → 혈액형(ABO) → 적록색맹(반성유전) 순으로, 과학은 "엄마는 할머니의 친딸일까?"라는 질문을 확인하는 도구로 쓰인다. 들어맞는 증거와 증명의 차이도 이야기 속에서 다룬다. 각 추리 뒤의 "📖 개념 정리"에서 교과서식 설명을 볼 수 있다.

## 사용 방법

1. 위 링크에 접속하거나, `index.html`을 브라우저로 엽니다.
2. 화면 아래 대화창을 클릭(또는 스페이스·엔터)해 이야기를 넘깁니다.
3. 장면 속에서 점선 고리와 함께 빛나는 물건을 눌러 살펴보면, 양피지 가계도가 펼쳐집니다.
4. 대화창의 선택지로 수수께끼를 풀면 소지품을 얻고 다음 방의 문이 열립니다. 막히면 💡 힌트를 펼쳐 보세요.
5. 진행 상황은 브라우저의 localStorage에 저장되어 이어서 플레이할 수 있습니다.

## 화면 구성

- **장면:** 방마다 그린 16:9 일러스트(흔들리는 시계추·촛불·까마귀, 비네트와 필름 그레인)
- **대화창:** 화자 이름표와 타자기 효과, 대화창 안에서 고르는 선택지
- **가계도:** 문제에서 살펴볼 사람에게 빨간 점선 동그라미가 그려진 양피지 문서
- **소지품:** 방을 해결할 때마다 얻는 열쇠·편지·교과서 (마우스를 올리면 설명)
